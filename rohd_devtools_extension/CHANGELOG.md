# ROHD DevTools application notes

This private Flutter application is not independently published or released.
CI builds its web bundle and includes it in the ROHD core pub.dev package under
`extension/devtools`.

The `version` in `pubspec.yaml` is Flutter build metadata. Release notes for
the application are recorded in the root [`CHANGELOG.md`](../CHANGELOG.md) as
part of the containing ROHD release.
