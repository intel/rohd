Convenience: synthesize top into a combined netlist JSON string.

Builds a SynthBuilder internally and returns the full JSON.

The packageRoot parameter is accepted for API compatibility with downstream trace-enabled branches. slimMode overrides the configured output mode for this call, allowing expansion after a slim request.
