NetlistService

NetlistService class

A service that wraps netlist (Yosys JSON) synthesis of a Module hierarchy.

Provides access to the full hierarchy JSON and per-module JSON with lazy caching, and optionally registers with ModuleServices for DevTools inspection.

Example:

final dut = MyModule(...);
await dut.build();
final netlist = NetlistService(dut);

// Full hierarchy JSON:
print(netlist.json);

// Single module (lazy, cached):
print(netlist.moduleJson('FilterChannel'));
