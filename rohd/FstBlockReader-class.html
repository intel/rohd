FstBlockReader

FstBlockReader class

Lightweight reader that decodes VcData DynamicAlias2 blocks written by FstWriter.

Uses the FstWriter.blockIndex to locate blocks on disk and reads only the requested signals, avoiding loading the entire FST file into memory.

Architecture

During a live simulation the data flow is:

FstWriter  ──(flushBlock)──>  .fst file (VcData blocks on disk)
                                  │
FstBlockReader ────(readBlock)────┘
                                  │
WaveformDataService  <──(merge)──── disk data + hot buffer
    │
    └──(VM Service extensions)──> DevTools extension

Post-simulation, the finalized .fst file can be read by the wellen library (Rust, via dart_wellen) in the rohd-wave-viewer for full waveform browsing.
