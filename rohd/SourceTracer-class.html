SourceTracer

SourceTracer class

Captures and stores stack traces for signal and submodule construction sites, allowing later queries by hierarchical address.

Constructing an instance activates recording; all Logic and Module constructors that follow will have their call-sites captured.

Example:

SourceTracer.activate();          // activate tracing
final mod = MyModule(a, b);   // Logic constructors record stack traces
await mod.build();

// Query a specific signal by hierarchical address
final trace = SourceTracer.traceOf(mod, 'myInternalSignal');
print(trace);

// Or get all traces for the module
final all = SourceTracer.tracesForModule(mod);
for (final entry in all.entries) {
  print('${entry.key}:\n${entry.value}\n');
}
