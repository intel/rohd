PairInterfaceSplit

PairInterfaceSplit<InterfaceType extends PairInterface> extension

Splitting utilities for a PairInterface.

The returned endpoint types allow module constructors and registration helpers to require a provider or consumer at compile time. Existing PairInterface APIs remain available when a dynamic role is needed.
