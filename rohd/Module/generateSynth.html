Returns a synthesized version of this Module.

Currently returns one long file in SystemVerilog, but in the future may have other output formats, languages, files, etc.

For richer access to per-module file contents, named maps, and individual file writing, see SystemVerilogService (and SystemVerilogService.output for the equivalent one-shot string). The configuration controls options specific to SystemVerilog output.
