frameRe property

RegExp frameRe
final

A regular expression that matches Dart stack-trace frames of the form: #N description (URI:line:col) or #N description (URI:line)

Implementation

static final frameRe = RegExp(
  r'#\d+\s+' // frame number
  r'(.+?)\s+' // description (function / constructor)
  r'\((.+?)' // opening paren + URI
  r':(\d+)(?::(\d+))?' // :line and optional :col
  r'\)', // closing paren
);
