defaultSkipPatterns constant

List<String> const defaultSkipPatterns

Patterns matched against the URI portion of each stack frame to decide which frames to skip. A frame is skipped when its URI contains any of these substrings.

The defaults remove SourceTracer internals, the Dart SDK, and common test-framework frames.

Implementation

static const defaultSkipPatterns = [
  'source_tracer.dart',
  'package:rohd/src/signals/',
  'package:rohd/src/module.dart',
  'package:rohd/src/modules/', // Primitives: gates, flops, pipeline, etc.
  'package:rohd/src/utilities/',
  'package:test_api/',
  'package:test_core/',
  'dart:', // All Dart SDK internals (dart:core, dart:_internal, etc.)
  'dart-sdk/', // DDC web format for Dart SDK frames
];
