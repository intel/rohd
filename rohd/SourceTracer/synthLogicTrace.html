Returns the stringified stack trace for the Logic selected to name synthLogic within module, or null.

A synthesized net often merges several Logics (e.g. a submodule output port and the internal intermediates that consume it). The namer already chooses one of them as the net's name source; attributing the trace to that same Logic makes cross-probe / FLC data point at the declared signal instead of an arbitrary internal signal that happens to appear first in the merge.

Falls back to the first member Logic of synthLogic that has a recorded trace (e.g. for a constant net with no single source Logic).

Implementation

static String? synthLogicTrace(
  Module module,
  SynthLogic synthLogic, {
  Map<SynthLogic, Logic>? sourceLogics,
}) {
  final cur = _current;
  if (cur == null) {
    return null;
  }
  final source = sourceLogics?[synthLogic];
  if (source != null) {
    final trace = cur._signalTraces[source];
    if (trace != null) {
      return trace;
    }
  }
  for (final logic in synthLogic.logics) {
    final trace = cur._signalTraces[logic];
    if (trace != null) {
      return trace;
    }
  }
  return null;
}
